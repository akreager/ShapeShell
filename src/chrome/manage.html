Extensions

Supported extensions have been tested with ShapeShell. Updates are never installed automatically. Pinned extensions appear in the toolbar.

    Unsupported extensions:

    Install an unsupported extension?

    This extension has not been tested with ShapeShell. It will very likely not work, and it may break things.

    • ShapeShell supports only part of Chrome's extension API; missing features fail silently.
    • It can read and change Onshape pages, including your documents and sign-in.
    • If it misbehaves, remove it here. No support is offered for unsupported extensions.
